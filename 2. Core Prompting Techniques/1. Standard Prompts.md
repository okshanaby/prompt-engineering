### Standard Prompts — Simple Summary

#### What Are Standard Prompts?

A **standard prompt** is simply a direct question or instruction given to an AI model.

Examples:

* "Write a JavaScript function to sort an array."
* "Explain why thunder is loud."
* "When was Apex Legends released?"

No special formatting or advanced techniques are used.

#### Why They Work

Standard prompts are the foundation of all prompting techniques.

They work like asking a person for help:

* **Vague question → Vague answer**
* **Specific question → Specific answer**

For example:

* ❌ "This code doesn't work."
* ✅ "On line 56, when I pass an empty array, I get this error..."

The more context you provide, the better the AI can help.

#### Example

A prompt like:

```txt
Create a prompt library app where users can save and delete prompts using localStorage, with HTML, CSS, and JavaScript.
```

can generate a working application from a single instruction.

#### Limitations

* AI models are **non-deterministic**, so outputs may differ each time.
* Models often make assumptions and add extra features you didn't ask for.
* This can introduce unwanted complexity, especially in coding projects.

#### Best Practice

When generating code:

* Be specific about requirements.
* Clearly state what should and should not be included.
* Use tools like code assistants that can directly access your project files to avoid constant copy-pasting.

### Example Standard Prompt:
```txt
Create a prompt library application that lets users save and delete prompts.

Users should be able to:

* Enter a title and content for their prompt
* Save it to localStorage
* See all their saved prompts displayed on the page
* Delete prompts they no longer need

Make it look clean and professional with HTML, CSS, and JavaScript.
```
