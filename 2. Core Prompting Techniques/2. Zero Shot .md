### Zero-Shot Prompting — Explanation & Summary

**Zero-shot prompting** means giving an AI a task without providing any examples. You simply describe what you want, and the model relies on what it already learned during training to complete it.

It is very similar to a **standard prompt**, but the key idea is:

* **No examples are provided**
* The model must infer the solution on its own

In practice, most simple prompts you already write are zero-shot without realizing it.

### When to Use It

Zero-shot prompting works best for:

* Simple or common tasks
* Tasks the model has likely seen before (e.g., coding, classification, summarization)
* Quick outputs where examples are unnecessary

Examples include:

* Sentiment classification (positive/negative/neutral)
* Code generation
* Proofreading or summarizing text
* Basic data extraction or labeling

It is efficient because it avoids extra examples, saving time and tokens while still producing good results for straightforward tasks.

### Example Zero-Shot Prompt

A more complex example is building a full prompt library app:

```txt
Create a prompt library application in HTML, CSS, and JavaScript.
Create an HTML page with a form containing fields for the prompt title and content

Add a save prompt button that saves to localStorage

Display saved prompts in cards

Each prompt card should show the title, a content preview of a few words, and a delete button

Deleting should remove the prompt from localStorage and update the display

Style it with CSS to look clean and modern with a developer theme

Include all HTML structure, CSS styling, and JavaScript functionality in their own files, but that can be run immediately and includes no other features.
```

### One-Sentence Summary

**Zero-shot prompting is when you give an AI a task with no examples, relying entirely on its prior knowledge to generate the correct output.**
