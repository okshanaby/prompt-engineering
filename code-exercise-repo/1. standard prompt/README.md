# Standard Prompt — Exercise

## Technique

**Standard Prompt** — a single, direct instruction given to an AI model with no special formatting or advanced prompting techniques.

## Prompt Used

> Create a prompt library application that lets users save and delete prompts.
>
> Users should be able to:
>
> - Enter a title and content for their prompt
> - Save it to localStorage
> - See all their saved prompts displayed on the page
> - Delete prompts they no longer need
>
> Make it look clean and professional with HTML, CSS, and JavaScript.

## Model

**Claude Sonnet 4.6** (`claude-sonnet-4-6`)

## Effort

**LOW** (Minimal) — no follow-up iterations or corrections needed. The model generated a complete, working application from a single instruction.
