### Delimiters / XML Prompting — Explanation & Summary

**Delimiters (including XML-style tags)** are a prompting technique used to clearly separate and organize different parts of input text so the AI can understand structure more easily.

They act like **boundaries or labels** inside a prompt, similar to:

* Bullet points in slides
* Headings in articles
* Sections in documentation
* Brackets or tags in code

Instead of giving the model one large block of unstructured text, you break it into **clear sections with meaning**.

---

### Why Delimiters Help

LLMs perform better when:

* Information is clearly separated
* Different parts of a task are labeled
* Structure is consistent and predictable

This helps the model:

* Understand what belongs together
* Prioritize different sections correctly
* Avoid mixing instructions, data, and context

You can even create your own delimiter style—as long as you stay consistent.

---

### When to Use Them

Use delimiters when:

* Prompts are long or complex
* You have multiple tasks in one prompt
* You need structured reasoning or analysis
* You are passing data + instructions together
* You want cleaner, more reliable outputs

---

### Example Delimiter-Based Prompt

```text prompt id="del1"
I need to research how existing tools handle prompt management and version control to inform architecture decisions for a prompt library I'm building and hoping to move to production. Please research and analyze different approaches using this structure:

<research_area>
<topic>Prompt Management Solutions</topic>
<questions>
- What tools currently exist for prompt library management?
</questions>
</research_area>

<research_area>
<topic>Collaboration Features</topic>
<questions>
- How do teams share Postman collections or Insomnia workspaces?
- What permission models exist in developer tools?
</questions>
</research_area>

<research_area>
<topic>Technical Implementation Details</topic>
<questions>
- What databases do similar tools use (research from their engineering blogs)?
- How do they handle search at scale?
- What's their approach to data export/import?
- How do they prevent abuse and implement rate limiting?
</questions>
</research_area>

For each research area:
1. Find concrete examples from real products
2. Identify patterns across successful tools
3. Highlight common failures or user complaints
4. Estimate implementation complexity

Then synthesize this into:
- A competitive analysis matrix
- Recommended features for our MVP vs future releases
- Technical decisions informed by market research
```

---

### One-Sentence Summary

**Delimiters and XML-style prompting improve AI performance by clearly structuring prompts into labeled sections, making complex instructions easier for the model to understand and follow accurately.**
