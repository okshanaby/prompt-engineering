### Tokens & Context Windows — Simple Summary

#### Tokens

* Tokens are the units AI models process, similar to how humans use words.
* A token is **roughly 0.75 words**, but it varies.
* Tokens can represent:

  * Words
  * Parts of words
  * Code
  * Punctuation
* The exact token count isn't important; just know that AI reads and generates text as tokens.

#### Context Windows

* A context window is the amount of information (tokens) an AI can keep track of at one time.
* AI models do **not truly remember** previous conversations.
* Instead, every time you send a message, the conversation history is included again so the model can reference it.

#### How "Memory" Works

* The AI appears to remember because it repeatedly receives the chat history.
* As conversations get longer, they consume more tokens.
* Once the context window limit is reached, older messages start being removed.

#### Important Limitation

* Context is removed on a **First In, First Out (FIFO)** basis.
* The oldest messages disappear first.
* The AI usually does **not tell you** when this happens.
* Important instructions given early in a long conversation may be forgotten once they fall outside the context window.

#### Why This Matters

* Long chats can lose important context.
* Sometimes it's better to start a new chat or restate important information.
* Understanding context windows helps you use AI more effectively and avoid unexpected behavior.

### One-Sentence Summary

**Tokens are the pieces of text an AI processes, and a context window is the maximum number of tokens it can keep track of before older information starts being forgotten.**
